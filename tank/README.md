# Laser Tag Robot Tank designs

These are the CAD files for Laser Tag Robot Tank. The
[laser tag robot tank repository](https://github.com/ngroesz/laser_tag_robot_tank)
contains the software for the tank as well as most of the documentation.

# Manufacturing

All prints created on a Creality Ender 5 with PLA filament. If you want to 
print these designs yourself, you will want to use the STL and use a slicer
with settings appropriate for your printer setup.

# Acknowledgements
